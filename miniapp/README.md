# Scout Mini App — выбранный тёмный интерфейс

Основа — предоставленный владельцем `freelance-ai-scout.zip`. Сохранены графитовая
палитра, сиреневые акценты, карточка заказа и компоненты обзора и каналов.
Презентация трёх экранов преобразована в мобильный интерфейс с нижней навигацией.

Это **демоверсия интерфейса**, пока без подключения к Python-боту, базе и Telegram
Mini Apps API. Данные, каналы, ИИ-рейтинг и текст отклика — примеры. Никакие
действия не отправляют сообщения, не обращаются к Telegram и не меняют базу бота.
Изменения в макете сохраняются только в памяти страницы, до перезагрузки.

## Просмотр

Открой `miniapp/index.html` в браузере либо запусти из корня репозитория:

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory miniapp
```

Локальный адрес: `http://127.0.0.1:8080`.
Пакеты, сборка, токены и запуск Bot API polling не нужны.

## Что можно попробовать

- Обзор: периоды 24 часа / 7 / 30 дней, демопауза мониторинга, переход к находке.
- Заказы: пояснение ИИ-рейтинга, редактирование и сохранение образца отклика,
  обратимая отметка «Не подходит». Исходная ссылка честно обозначена как неподключённая.
- Каналы: поиск, переключение активности, удаление из демо, проверка формата и
  повторов при добавлении `@username` или ссылки `https://t.me/username`.
- «Сбросить демо» возвращает начальные данные. Ссылки нижнего меню поддерживают
  адреса `#overview`, `#orders`, `#channels` и историю браузера.

## Следующий этап: подключение

Нужен серверный API поверх существующих `Repository` и `ScoutService` без второго
экземпляра Bot API polling. Перед выдачей данных или изменениями сервер должен
проверять подписанные Telegram `initData`, срок их действия и `OWNER_ID`.
Токен бота, Telegram-сессия и ключ ИИ не должны попадать в браузер.

Далее следует заменить демоданные настоящими заказами, анализами и статистикой;
подключить действия к серверу с обработкой ошибок; сохранить подтверждение новых
каналов владельцем и отсутствие автоматической отправки откликов.
Пауза мониторинга на этом экране — проектируемая функция: наличие кнопки не
подтверждает, что в текущем сервисе уже есть глобальная пауза.

Для запуска в Telegram также нужны HTTPS-адрес, настройка кнопки Mini App в боте,
поддержка Telegram viewport/safe area и проверка в клиентах Telegram. Эта папка
сама по себе не включает развёртывание или доступ к работающему боту.
